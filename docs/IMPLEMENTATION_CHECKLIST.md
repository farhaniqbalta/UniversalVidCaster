## Scope

Build a desktop Chrome test harness that uses reusable TypeScript modules to
cast direct media to an existing Google Cast device through the official Web
Sender SDK and Default Media Receiver. No TV app or custom receiver is required.
M0 does not establish iPhone Safari compatibility.
